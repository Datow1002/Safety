2 高風險作業危害題庫（支援多工種複選 / 點擊取消）

可同時複選如「高處 + 動火 + 電氣」，系統將自動合併去重

潛在危害因素 (14)
  • 1.高處作業人員墜落、滾落危害（2公尺以上開口/施工架）
  • 2.施工架踏板未滿鋪、未設護欄或中欄杆導致失足
  • 3.上層手工具、螺絲或物料飛落擊傷下方人員
  • 4.移動式施工架未鎖定輪煞或違規帶人移動傾倒
  • 5.合梯作業未設防止開展拉桿或跨坐頂板作業
  • 6.地面管線、電線凌亂或濕滑導致人員絆倒、滑倒
  • 7.重物人工搬運姿勢不當造成腰部扭傷或物料滑落壓傷手足
  • 8.尖銳鐵件、裸露鋼筋或毛邊割傷、穿刺傷
  • 9.高溫環境作業未適時補水休息引發中暑或熱衰竭
  • 10.誤觸活線端子或未斷電作業引發嚴重感電傷亡
  • 11.斷電檢修期間遭他人誤送電（未上鎖掛牌 LOTO）
  • 12.臨時用電分電盤未裝設漏電斷路器或電線浸泡積水
  • 13.電氣短路產生電弧灼傷或引發電氣火災
  • 14.照明不足或潮濕手部接觸開關箱導致漏電感電
危害防範與安全對策 (14)
  • 1.2公尺以上作業全程佩帶背負式安全帶並「雙掛鉤」勾掛於安全母索
  • 2.施工架每日作業前檢點：滿鋪踏板、護欄高度90cm以上、腳趾板齊全
  • 3.手工具應繫妥防墜繩，下方劃設危險警告區並禁止無關人員進入
  • 4.移動式施工架作業時四輪煞車確實鎖緊，嚴禁人員停留於架上推行
  • 5.使用合格A字合梯（具堅固金屬拉桿），嚴禁站立於頂板或最上一階
  • 6.維持走道暢通與照明充足，地面油漬積水立即清除，裸露鋼筋加裝護套
  • 7.重物搬運優先使用推車或兩人以上協同搬運，保持背部平直以腿部施力
  • 8.使用電動手工具前檢查電線絕緣與護罩完整，確實配戴護目鏡與防割手套
  • 9.定時補充飲水與電解質，身體不適立即停止作業並通報領班
  • 10.作業前確實切斷電源、驗電確認無電，並執行「上鎖掛牌(LOTO)」由專人保管鑰匙
  • 11.所有臨時用電迴路必須經由高感度高速型漏電斷路器（ELCB: 30mA, 0.1秒）
  • 12.電線採取架高佈設避免重壓破損，接頭處使用防水絕緣插座
  • 13.活線接近作業必須穿戴合格絕緣手套、絕緣靴並鋪設絕緣毯
  • 14.配電盤旁備妥二氧化碳(CO2)或乾粉滅火器，嚴禁濕手操作電氣開關

步驟 1：已授權的 JavaScript 來源網址
前往 Google Cloud Console ↗
點我看免費申請 4 步驟（約 2 分鐘）
  1. 建立專案 →「API 和服務 → 程式庫」啟用 Google Drive API。
  2. 「OAuth 同意畫面 / Google 驗證平台」選 外部 (External)，建好後務必點 「發布應用程式 (Publish App)」，讓所有同事的帳號都能登入。
  3. 「用戶端 / 憑證 → 建立用戶端 → OAuth 用戶端 ID → 網頁應用程式」，填入您 GitHub Pages 的主網域（如 https://帳號.github.io）於「已授權的 JavaScript 來源」。
  4. 將 ...apps.googleusercontent.com 貼到下方欄位。
步驟 3：一鍵打包下載「index.html」（直接上傳 GitHub）
不想碰 Google Cloud？ 直接到 script.google.com 建立新專案，貼上 Code.gs 與 Index.html，部署時將「執行身分」選為 「存取網頁應用程式的使用者」，即可免申請任何金鑰，登入者各自存取個人雲端硬碟！
